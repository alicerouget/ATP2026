## Resumo
Nas atividades do Turtle e Maze do Blockly Games – nível 10, utilizei blocos de programação para criar desenhos e resolver percursos. No Turtle, construí um barco com ondas, utilizando movimentos, rotações, repetições e medidas para manter a proporcionalidade. No Maze, utilizei ciclos e condições para controlar os movimentos e encontrar o caminho até ao objetivo, evitando os obstáculos.
